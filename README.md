A tiny Node 22 program for the make.fun bounty
[The One-Line Exit](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1).

`main.ts` writes one resignation letter to `/output/entry.txt`: a
night-shift security guard quits on the spot because the ghosts in aisle
four have unionized — and frankly offer better benefits. A specific voice,
a surprise turn, and the punchline lands on the last word. No network, no
randomness, no input — the same line on every run.

Run it with Node 22:

```sh
node main.ts
```
